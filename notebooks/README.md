# Notebooks

El flujo reproducible oficial está en la CLI: `traveler demo-train`, `traveler evaluate`, `traveler train` y `traveler predict`.

Para Colab, cargar el ZIP, descomprimirlo, `cd traveler_insights_2026`, ejecutar `pip install -e '.[test]'` y continuar con CLI. **No se recomienda entrenar en datos de ejemplo para reportar rendimiento**.
